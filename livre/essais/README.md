# Les programmes d'essai du livre

Chaque programme que le livre te fait écrire est ici, rangé par chapitres :
`chapitres-01-04`, `chapitres-05-08`, `chapitres-09-11` et `chapitres-12-14`.

Le livre te les fait taper toi-même. Ils sont là pour comparer avec ton
travail quand quelque chose ne marche pas. Toutes les commandes du livre se
lancent depuis la racine du dépôt.
